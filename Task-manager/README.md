# Task Manager App

#  Backend Setup
1. cd Backend
2. npm install
3. node server.js (runs on port 4000)

#  Frontend Setup
1. cd frontend
2. npm install
3. Create a `.env` file with `VITE_API_URL=http://localhost:4000/api/tasks`
4. npm run dev (runs on port 5173)

# API Endpoints
- GET /api/tasks
- POST /api/tasks
- PUT /api/tasks/:id
- DELETE /api/tasks/:id
- PATCH /api/tasks/:id/toggle
