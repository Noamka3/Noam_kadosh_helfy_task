# Task Manager App

# Prerequisites
- Node.js 18 

#  Backend Setup
1. cd Task-manager/Backend
2. npm install
3. node server.js (runs on port 4000)

#  Frontend Setup
1. cd Task-manager/frontend
2. npm install
3. npm run dev (runs on port 5173)

# API Endpoints
- GET /api/tasks
- POST /api/tasks
- PUT /api/tasks/:id
- DELETE /api/tasks/:id
- PATCH /api/tasks/:id/toggle
